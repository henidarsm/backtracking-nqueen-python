# Implementasi Algoritma Backtracking — N-Queens Problem
## Deskripsi
Program ini mengimplementasikan algoritma Backtracking untuk menyelesaikan N-Queens Problem menggunakan Python dengan visualisasi langkah-langkah di CLI. N-Queens Problem adalah masalah menempatkan N buah ratu pada papan catur N×N sehingga tidak ada dua ratu yang saling menyerang.
## Cara Menjalankan
python nqueen.py — untuk ubah N tinggal ganti nilai N = 4 di dalam kode.
